## 혜선에게

혜선아, 내가 연락을 자주 했는데 연락이 단절돼서 — 무슨 이유가 있나 싶어서
연락을 못 하고 있었어. 연락이 되면 좋겠고.

오랜만에 깃허브를 보다가 최근에 업데이트한 게 있어서 들어와 봤다가,
수정할 수 있는 조그만 것들을 해줬어. 어떻게 고쳤는지는 아래에 적어 뒀다.

## 이게 뭔가

가족 여행을 갔다 오면 흩어지는 것들 — "언제 어디 가기로 했지", "사진 어디 있지",
"얼마 썼지", "뭐 했더라" — 를 **여행 하나 = 기록장 하나**에 모아 두는 앱.

여행을 열면 탭이 나온다.

| 탭 | 무엇 |
|---|---|
| **일정** | 지도 위에 하루 동선. 가는 길·걸리는 시간·다음 목적지까지 앱이 계산한다. "10시에 출발" 하면 그날 시간표가 쭉 나온다 |
| **앨범** | 날짜별 사진첩. 사진을 올리면 찍은 시각으로 그날 갔던 장소가 자동으로 붙는다 |
| **가계부** | 날짜별 지출 장부. 카드사 문자·CSV를 붙여 넣으면 항목으로 갈라 담긴다 |
| **일기** | 그날 사진을 장면으로 묶어 손글씨 스크랩북으로. 장면마다 제목·문장·말풍선 |
| **함께** | 여행 멤버. 초대 링크를 만들거나, 들어온 참가 신청을 허용·거절한다 |
| **대화** | 여행별 단체방 + 일대일. 메시지에 여행 카드를 붙일 수 있다 |

그리고 어디서든 **냥이에게 말로 부탁**할 수 있다 — "다음 어디로 가?"라고 하면
Chief가 이게 일정 얘기인지 가계부 얘기인지 알아서 담당 냥이에게 넘긴다.

## 냥이들

화면에서는 이름과 등급만 보인다. 모델명·도구 같은 속은 숨겼다.

| 냥이 | 등급 | 맡는 것 |
|---|---|---|
| **Chief** | — | 말을 듣고 알맞은 냥이에게 넘긴다. 직접 일은 안 한다 |
| **Planner** | 똑똑함 | 일정 — 지금 어디 있는지, 다음 갈 곳, 동선 다시 짜기 |
| **Designer** | 똑똑함 | 지도 데이터가 없는 여행의 하루 시간표 |
| **Album** | 가벼움 | 사진 캡션, 여행일기 글 |
| **Ledger** | 가벼움 | 가계부 정리·요약 |
| **Pass** | 가벼움 | 패스권 — 어떤 권종 조합이 제일 싼지 계산 |

중요한 규칙: **숫자는 냥이가 지어내지 않는다.** 거리·시각·손익분기 같은 산수는
전부 코드(`lib/`)가 결정적으로 계산하고, 모델은 말로 옮기기만 한다. 일정 변경
같은 도구도 "제안"까지만 만들고, 마지막 확정은 사람이 누른다.

## 이번에 손 본 것

화면 위주로 조금씩 다듬었다.

- **여행 목록 → 사진 앨범** — 여행 카드를 폴라로이드처럼. 첫 사진이 표지,
  없으면 테마색 빈 사진, 제목은 손글씨. "+ 새 여행"은 빈 앨범 페이지다.
- **여행 찾기** — 분홍 카드 + 둥근 검색창. 결과는 카드로, 신청 상태는
  색깔 칩(대기·거절·멤버)으로, 이미 들어온 여행은 "열기 →" 로 바로 간다.
- **냥이 소개 카드** — 이름은 영어로(Planner · Designer · Pass · Album ·
  Ledger), 모델명·도구 목록은 숨기고 **가벼움 / 똑똑함** 칩만 보여 준다.
- **새 여행 날짜** — 브라우저 기본 날짜 칸 대신 shadcn/ui 달력. 한국어
  요일·월로 나오고 시작–끝을 한 번에 고른다. 눌러서 여는 팝오버.
- **알림 종** — 누르면 바닥에서 시트가 올라와 알림 목록. 볼 게 없으면
  시트 대신 토스트로 "새로 볼 알림이 없습니다"만 잠깐 띄운다.
- **불러오는 중** — 글자 대신 비행기가 점선 항로를 날아 도착 핀에 앉는다.
- **말투** — 일반 화면에서 "에이전트"라는 단어를 뺐다. 담당 냥이, Chief.

## 실행하기

```bash
cd webapp
npm install                 # shadcn 달력 부품까지 같이 깔린다
cp .env.example .env.local  # 안에 칸마다 설명이 붙어 있다
npm run dev                 # http://localhost:3000
```

처음 켜면 `/setup` 에서 관리자를 만들고(`SETUP_CODE`), 그다음부터는 `/signup`
으로 가입한다. 카카오로그인 단추는 카카오 키 세 개를 넣으면 저절로 생긴다.

### 환경 변수

`.env.example` 을 복사해서 채운다. **최소로 필요한 건 DB 하나뿐.**

| 키 | 값 | 없으면 |
|---|---|---|
| `DATABASE_URL` | `file:./data/trip.db` (로컬) / Turso 주소 (배포) | 껐다 켜면 다 날아간다 |
| `DATABASE_TOKEN` | Turso 토큰 | 로컬 파일 DB면 비워 둔다 |
| `SETUP_CODE` | 첫 관리자를 만들 때 묻는 문답 암호 | `/setup` 이 열리지 않는다 |
| `AGENT_PROVIDER` | `anthropic` 또는 `ollama` | 냥이가 규칙 모드로 떨어진다 |
| `ANTHROPIC_API_KEY` | Anthropic 키 | — |
| `AGENT_MODEL_QUICK` / `AGENT_MODEL_DEFAULT` | 가벼움/똑똑함 등급에 쓸 모델명 | 기본값 사용 |
| `AGENT_BASE_URL` | OpenAI 호환 주소 (ollama 면 `http://127.0.0.1:11434/v1`) | — |
| `OLLAMA_MODEL_*` | 로컬 모델명 (`qwen3:4b` 등) | — |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob 토큰 | 배포본에서 사진 업로드가 안 된다 |
| `DATA_GO_KR_KEY` | 공공데이터 키 | 일별 운영정보 조회만 쉰다 |

모델이 없어도 지도·일정·앨범·가계부·일기는 전부 돌고, 냥이만 규칙 모드로 떨어진다
(`GET /api/health` 의 `model` 이 `no_key` 로 보인다).

### 자주 쓰는 명령

```bash
npm run dev          # 개발 서버
```

```
│  ├─ src/app/                     화면 + REST 라우트
│  ├─ src/agents/                  냥이 하네스 · 프롬프트 · 도구 · 총괄
│  ├─ src/lib/                     저장소 · 일정 산수 · 지역팩 로더
│  ├─ src/components/              화면 부품 (ui/ 는 shadcn)
│  ├─ data/regions/                구워 둔 지역팩 — 경주 · 에버랜드
│  ├─ data/passes/                 패스권 가격표 (asOf·출처 명시)
│  ├─ android/ · ios/              Capacitor 네이티브 껍데기
│  └─ scripts/build_region.py      지역팩 빌더 (로컬에서만 실행)
└─ cat-*.jpg                       냥이 얼굴들 (README용)
```

두 판은 **섞지 않는다.** 아티팩트 판은 `window.claude.use()` 런타임에 얹혀 있어
배포하면 못 쓰고, `webapp/` 판이 그 후속이다.

## 만들어진 것 위에서

- **지도·도로망·관광지** — 빌드 타임에 OpenStreetMap에서 구운 지역팩 JSON.
  배포된 앱은 결과만 읽으므로 런타임에 파이썬도 외부 API 호출도 없다
- **일별 운영정보** — 요청 때마다 에버랜드 공식 API를 두드리고 30분 캐시
- **패스권 가격** — 공식 API가 외부 요청에 500을 내서 손으로 적었다.
  `asOf`·`sources`·`verifyUrl` 을 파일에 박아 두고, 냥이는 답할 때마다
  공식 확인을 권한다
- **DB** — libSQL/SQLite. 로컬은 파일 하나, 배포는 Turso. 스키마는 첫
  요청에 `CREATE_SQL`/`PATCH_SQL` 로 만든다
- **로그인** — scrypt + 세션 쿠키. 들어오는 길은 초대 링크 · 검색 신청 ·
  카카오 세 갈래. 멤버 권한은 owner / editor / viewer
- **냥이** — Vercel AI SDK v5. `AGENT_PROVIDER` 하나로 Anthropic ↔
  OpenAI 호환(ollama 등)을 갈아 끼운다
- **네이티브** — Capacitor 껍데기가 있다 (`npx cap sync` 로 웹 빌드를 넣는다)

## 아직 안 한 것

- 카카오 키를 배포 환경에 안 넣었다 — 넣으면 로그인 화면에 단추가 생긴다
- 알림이 앱 안에만 있다 — 메일·푸시로 나가지 않는다. 종을 봐야 안다
- 개인 레이어("이 일정에서 난 여긴 빠진다")의 나만 가는 곳은 순서 끝에
  붙는다 — 어디에 끼울지 고르는 화면이 없다
- 배포본 화면을 사람 눈으로 훑는 검증이 아직 없다

## 배포

```bash
cd webapp
npx vercel deploy --prod
```

DB는 Turso, 사진은 Vercel Blob. 프리뷰 배포는 Turso의 분기 DB를 쓰므로
프리뷰에서 만든 데이터는 프로덕션에 안 간다.

깊은 구조·REST API 표·총괄 스트림 형식·지역팩 굽는 법은
[webapp/README.md](./webapp/README.md)에 있다.
