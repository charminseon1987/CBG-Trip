## 혜선에게

혜선아, 내가 연락을 자주 했는데 연락이 단절돼서 — 무슨 이유가 있나 싶어서
연락을 못 하고 있었어. 연락이 되면 좋겠고.

오랜만에 깃허브를 보다가 최근에 업데이트한 게 있어서 들어와 봤다가,
수정할 수 있는 조그만 것들을 해줬어.

## 이번에 손 본 것

화면 위주로 조금씩 다듬었다.

- **여행 목록 → 사진 앨범** — 여행 카드를 폴라로이드처럼. 첫 사진이 표지,
  없으면 테마색 빈 사진, 제목은 손글씨. "+ 새 여행"은 빈 앨범 페이지다.
- **여행 찾기** — 분홍 카드 + 둥근 검색창. 결과는 카드로, 신청 상태는
  색깔 칩(대기·거절·멤버)으로, 이미 들어온 여행은 "열기 →" 로 바로 간다.
- **냥이 소개 카드** — 이름은 영어로(Planner · Designer · Pass · Album ·
  Ledger), 모델명·도구 목록은 숨기고 **가벼움 / 똑똑함** 칩만 보여 준다.
- **새 여행 날짜** — 브라우저 기본 날짜 칸 대신 shadcn/ui 달력. 한국어
  요일·월로 나오고 시작–끝을 한 번에 고른다. 눌러서 여는 팝오버.
- **알림 종** — 누르면 바닥에서 시트가 올라와 알림 목록. 볼 게 없으면
  시트 대신 토스트로 "새로 볼 알림이 없습니다"만 잠깐 띄운다.
- **불러오는 중** — 글자 대신 비행기가 점선 항로를 날아 도착 핀에 앉는다.
- **말투** — 일반 화면에서 "에이전트"라는 단어를 뺐다. 담당 냥이, Chief.

## 실행

```bash
cd webapp
npm install                 # shadcn 달력 부품까지 같이 깔린다
cp .env.example .env.local  # 안에 칸마다 설명이 붙어 있다
npm run dev                 # http://localhost:3000
```

`.env.local` 에 최소한 이것만 있으면 된다 — 파일 DB 하나.

```
DATABASE_URL=file:./data/trip.db
```

냥이 채팅까지 돌리려면 모델 길이 하나 더 필요하다 — `AGENT_PROVIDER`
(anthropic 또는 ollama 호환 주소) 를 .env.example 대로 채우면 된다.
모델이 없어도 지도·일정·앨범·가계부·일기는 전부 돌고, 냥이만 규칙 모드로 떨어진다.

처음 켜면 `/setup` 에서 관리자를 만들고, 그다음부터는 `/signup` 으로 가입한다.

## 구조

| 폴더 | 무엇 |
|---|---|
| 루트 `route-1003.html` · `agent-*.js` | Claude Artifact 판 (원본) |
| `webapp/` | 배포용 웹앱 — Next.js 15 · React 19 · Tailwind v4 |

깊은 구조·API·지역팩 이야기는 [webapp/README.md](./webapp/README.md)에 있다.
배포는 `webapp` 에서 `npx vercel deploy --prod`.

## 만들어진 것 위에서

- 지도·도로망·관광지: 빌드 타임에 구운 지역팩 JSON (OpenStreetMap, ODbL)
- DB: libSQL/SQLite — 로컬은 파일 하나, 배포는 Turso
- 로그인: scrypt + 세션 쿠키, 초대 링크·검색 신청·카카오 세 갈래로 들어온다
- 냥이: 총괄이 분류해 넘기고, 담당은 자기 도구만 쓴다. 모델이 숫자를
  지어내지 않게 거리·시각·패스권 산수는 `lib/` 의 결정적 함수가 한다
